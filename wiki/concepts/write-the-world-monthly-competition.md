# Write the World 月度竞赛

Write the World 是创办于 2012 年的国际青少年写作社群，每月举办不同主题和写作类型的竞赛，涵盖诗歌、小说、时评、个人叙事等多种体裁。活动面向全球 13–19 岁学生，全年滚动举办，以低门槛、高频次、专家反馈为核心特色。

## 赛事基本信息

- **主办方：** Write the World
- **官网：** <https://writetheworld.org/competitions/all>
- **面向人群：** 13–19 岁全球青少年（建议托福 80+）
- **频率：** 每月一场，每月全新主题
- **报名费用：** 无
- **建议备赛周期：** 约 1 个月

## 赛制特色

- **专家反馈：** 每场比赛最先提交的 50 份作品可获评审专业反馈，可据此修改后再次提交，以提高获奖概率。
- **同伴互评：** 所有参赛选手可互相进行作品互评，评审也会从中选出最佳评论给予奖项和奖金。
- **体裁多样：** 每月主题不同，涵盖诗歌、短篇小说、时评、个人叙事、闪小说、歌词创作等。
- **获奖待遇：** 获奖作品可获颁奖金、作品发表及官方采访机会。

## 奖项设置

- **冠军（Winner）：** 通常 $100 奖金 + 客座评委签名书籍
- **亚军（Runner-up）：** 通常 $50 奖金
- **最佳同伴评议奖（Best Peer Review）：** $50 奖金

## 赛事定位

在 Thinktown 竞赛分级体系中，Write the World 月度竞赛被列为"初级"赛事，适合 6–7 年级学生作为入门练习，也适合更高年级学生以赛代练、积累写作经验。其低门槛和专家反馈机制使其成为写作新手的理想练兵场。

## Thinktown 辅导产品

新课堂提供全程 1v1 学科咨询类课程辅导，形式包括实时互动（CT，如授课讨论）与非实时互动（NCT，如文章修改反馈），根据学生具体情况制定个性化课程安排；其中"ABC 咨询课程（学科-定制）"单价 ¥1,000，师资为梁嘉颖。
