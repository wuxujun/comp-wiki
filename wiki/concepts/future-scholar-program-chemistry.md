# 未来学者化学科研计划

未来学者计划（Future Scholar Program）是新课堂国际教育（Thinktown Education）推出的化学学科科研项目，面向 9–12 年级国际课程学生，旨在帮助学生掌握常用的化学科研知识和方法。项目通过一对一辅导，覆盖从文献检索到学术演讲的全流程，帮助学生完成个人论文产出，为国际课程论文写作及海外大学申请增加学术筹码。

## 适合群体

- 国际课程 9–12 年级学生
- 具备不错的英文读写能力与化学基础知识和实验技能
- 对化学相关方向的科研有热情，渴望通过体验化学科研项目证明自己学术能力
- 建议托福 100 分左右，国际课程化学科目达到 A 级

## 课程内容

项目总计 22 课时（13 课时 CT + 9 课时 NCT），涵盖六大模块：

| 模块 | 内容 |
|---|---|
| 科学素养的意义 | 科学素养及专利检索 |
| 论文和期刊检索 | 期刊检索及引用、文献软件介绍及使用、文献管理方法 |
| 选题与实验设计 | 个性化选题头脑风暴、科研实验流程讲解与实验设计辅导 |
| 数据收集与分析 | 数据制定与搜集、数据整理与分析 |
| 科研论文写作 | 写作方法与格式讲解、论文修改 |
| 学术演讲 | 演讲技巧与注意事项、演讲实操 |

## 产品亮点

- 一对一辅导，专业科研入门及写作指导
- 论文头脑风暴，论文修改自研讲义材料
- 由具备深厚化学学术背景的团队指导
- 根据学生选题方向和实验条件，选择一级或二级研究流程

## 报名与收费

- 报名需经督导/顾问联系学科负责人或学术顾问进行 Pre-talk 评估
- 课程通过 E 类 ABC 课程类型传递，单价为 1,000 元/课时
- 退费遵循《新课堂学习协议》
