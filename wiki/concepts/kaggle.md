# Kaggle 大数据竞赛

Kaggle 成立于 2010 年，2017 年被谷歌收购，是全球最知名的数据挖掘和预测竞赛在线平台。平台上大部分竞赛由科技公司、金融机构或研究者发布，以奖金悬赏方式征集数据科学解决方案。Kaggle 竞赛全年滚动发布，大部分比赛周期约 3 个月，绝大部分为 3–5 人团队赛，是大数据界含金量最高的竞赛之一。

## 赛制

- **形式：** 线上挑战，绝大部分为 3–5 人团队赛，也可单人参加。
- **报名费用：** 完全免费。
- **时间：** 全年滚动发布，大部分比赛周期约 3 个月。
- **面向人群：** 全年龄组，世界所有数据爱好者均可参加；建议高中生 10 年级以上（11 年级最佳），对数据科学与人工智能有浓厚兴趣，并有较强的自主学习能力。

## 奖项设置

| 奖项 | 标准 |
|---|---|
| 金奖（Gold Medal） | 一般为排名前 0.5% 的队伍 |
| 银奖（Silver Medal） | 一般为排名前 0.5%–5% 的队伍 |
| 铜奖（Bronze Medal） | 一般为排名前 5%–10% 的队伍 |

实际比例因比赛而异。

## 适合学生

- 有较扎实的 Python 基础，在概率论、线性代数、微积分方面有知识储备。
- 未来想申请计算机、（应用）数学、数据科学、统计学、生物信息学、商科（商业分析方向）等专业。
- 有 Java 或 C++ 基础的学生转 Python 较快。

## Thinktown 三阶段课程体系

| 阶段 | 课时 | 内容 |
|---|---|---|
| 第一阶段：基础知识 | 1v1/1v6，24 课时 | 机器学习工作流基本知识，完成 Titanic 教学赛 |
| 第二阶段：模拟训练 | 1v1，6 课时 | 完成 House Prices 教学赛 |
| 第三阶段：真实赛事 | 1v1，约 8–12 课时/赛 | 参与 Kaggle 赏金赛实战 |
