# Thinktown 赛事基础资料目录

本来源目录汇总 raw/docs 中主要来自 Thinktown 分享页的赛事与项目基础条目。它们通常记录参赛对象、形式、时间、难度、奖项和备赛建议，但不少条目缺少结构化摘要，且外部赛事事实仍需回到主办方核验。
这些文件共同显示，赛事选择通常围绕学科兴趣、年级与先修基础、个人或团队形式、备赛周期、成果类型和阶段晋级路径展开。

## 关键主张与使用边界

- 目录条目保留原始文件链接和外部来源类型，具体事实应以对应原文为准。
- 活动日期、价格、课时、报名规则、导师信息与奖项数据均可能随版本变化。
- 原文中的宣传判断、升学效果和成功率不能视为独立验证结论。
- 为避免扩散个人信息，本目录不摘录学生姓名、学校或联系方式。
