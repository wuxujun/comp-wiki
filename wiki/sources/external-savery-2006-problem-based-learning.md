# Savery 2006 年问题式学习定义来源

这篇基础综述梳理 Problem-Based Learning 的历史、定义及其与其他体验式教学方法的区别。它用于澄清 PBL 缩写歧义和问题式学习的核心，不用于判断 Project-Based Learning 的最新效果。

## 核心主张

- Problem-Based Learning 是以学习者为中心的教学与课程方法。
- 学习者围绕一个被界定的问题开展研究、整合理论与实践，并运用知识与技能形成可行解决方案。
- 问题不仅是练习题，而是驱动自我导向学习与知识整合的起点。
- 文章将 Problem-Based Learning 与案例法、项目式学习等体验式方法并列比较。
