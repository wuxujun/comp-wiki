## 核心主张

- Kaggle 成立于 2010 年，2017 年被谷歌收购，常年承办的大数据竞赛是大数据界最有含金量的竞赛之一。
- 报名完全免费，绝大部分为 3–5 人团队赛，也可单人参加，全年均有赏金赛事，大部分周期约 3 个月。
- 适合 10 年级以上、11 年级最佳的学生，需有较扎实的 Python 基础以及概率论、线性代数、微积分知识。
- Thinktown 三阶段课程体系：第一阶段数据科学基础知识（1v1/1v6，24 课时，完成 Titanic 教学赛）；第二阶段模拟比赛训练（1v1，6 课时，完成 House Prices 教学赛）；第三阶段真实赏金赛实战（1v1，每赛约 8–12 课时）。
- Thinktown 战绩：GoDaddy 金奖（Top 0.4%）、IceCube 铜奖（Top 8%）、AMP 银奖（Public Leaderboard Top 3%）、ICR 铜奖（Public Leaderboard Top 9%）。
- Q&A 指出：高中生在导师引导下完全有能力完成文献调研、数据清洗和模型调试任务；有 Java 或 C++ 基础的学生转 Python 很快；Thinktown 不对获奖做出保证。

## 可靠性说明

该宣传材料信息总体可靠。"有学员在学校组织 Kaggle 社团，最终被 CMU 计算机专业提前录取"为宣传性案例，无法独立验证。Public Leaderboard 成绩（AMP 银奖、ICR 铜奖）可能在最终排名中发生变化，因为 Kaggle 的 Public Leaderboard 仅反映部分数据的排名。三阶段课程的课时数为大致范围。
