# Thinktown 赛事分析与项目资料目录

本来源目录汇总 raw/docs 中的赛事指南、对比推荐、规划文章、辅导介绍和其他项目材料。它们比基础条目提供更多解释和营销语境，但具体日期、规则、难度与价值判断仍是带版本的二手信息。
这些文件常把赛事信息与课程、辅导、升学规划和成果案例结合起来，适合分析机构的选赛逻辑而非直接替代官方规则。

## 关键主张与使用边界

- 目录条目保留原始文件链接和外部来源类型，具体事实应以对应原文为准。
- 活动日期、价格、课时、报名规则、导师信息与奖项数据均可能随版本变化。
- 原文中的宣传判断、升学效果和成功率不能视为独立验证结论。
