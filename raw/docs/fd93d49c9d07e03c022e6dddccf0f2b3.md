# 081525 PBL-P02 CS-运动心力量 v1 from Cory

## 1. 基础段课程方案 (Beginner Level)

**侧重**

建立运动与情绪的基本连接，学习初步观察和记录方法，体验最基础的心理策略。

**概述**

本阶段旨在引导学生认识运动对情绪的积极影响，学习如何简单地观察运动前后的身体感受和情绪变化，并通过简单的积极自我对话，培养初步的乐观心态。学生将学习如何使用模板进行运动心理日志的记录，并为“青少年运动心理策略指南”奠定基础。

**教学目标**

* 理解运动对情绪的科学影响（如内啡肽与压力释放）。

* 学习识别和描述运动时的身体具体感受和情绪细微变化。

* 掌握积极自我对话的原理与实践技巧，并能初步重构消极想法。

* 运用结构化模板，撰写内容更丰富的运动心理日志。

* 初步构思个人“运动心理成长日志”和“青少年运动心理策略指南”的简单内容。

## 课程结构 (Lesson Breakdown) - 线上 1v1 形式

**第一课：运动、大脑与我的情绪地图**

* **核心内容：**

  - 运动与情绪的科学连接：简化讲解运动如何促使大脑释放“快乐激素”内啡肽，从而减轻压力和提升情绪。

  - 情绪的基础分类与识别：区分积极情绪（兴奋、快乐、满足）和消极情绪（沮丧、焦虑、疲惫），并学习如何在运动场景中识别它们。引入情绪轮或情绪词汇表，帮助学生精准表达。

  - 身心连接的概念：强调身体活动如何直接影响我们的心理状态，以及反之亦然。

* **活动与互动：**

  - 1v1 线上**“情绪词语速配”游戏**：老师给出运动场景（如“跑不动时”、“投中关键球时”），学生选择匹配的情绪词汇并简述原因。

  - 观看简短的科普动画或图片（例如大脑在运动时活跃的区域），老师用通俗语言解释运动对大脑的影响，引发学生对“为什么运动让我开心/放松”的思考。

  - 引导学生分享第一次注意到运动对情绪产生影响的经历。

* **作业与反思：** 尝试进行 15-20 分钟的轻度运动（如散步、跳绳），课后记录运动前后的“心情指数”和至少五种具体情绪词，思考它们之间的关联，并在作业中提交。

* **产出导向：** 为《运动心理成长日志》奠定扎实的科学认知基础。

**第二课：掌握你的内心声音——积极自我对话的奥秘**
* **核心内容：**

* 积极自我对话的原理：深入解释内心对话如何直接影响我们的自信心、专注力和实际表现，以及它如何改变我们的大脑思维模式。

* 识别与重构消极思维：学习如何识别运动中常见的**负面内心声音**（如“我做不到”、“我太累了”），并提供具体且可操作的模板，引导学生将这些消极想法转化为**积极、建设性的自我对话**。

* 积极自我对话的类型：介绍**鼓励型**（给自己加油）和**指导型**（告诉自己怎么做）两种常见类型。

* **活动与互动：**

* 线上**“思维转换练习”：** 老师提供多个运动中可能遇到的负面情景（如“踢不进球”、“跑不动”），学生即时口头或打字练习**重构**为积极的自我对话，老师进行即时反馈和修正。

* 共同创作**“我的运动咒语”：** 老师引导学生结合自身运动习惯，共同设计一套个性化、富有力量的**积极自我对话短句集**。

* **作业与反思：** 挑选 3-5 句个性化的积极自我对话（包括鼓励型和指导型），并在下次 20-30 分钟运动中尝试运用，记录它们在**实际运动中对情绪和表现的影响**，写下简要练习笔记提交。

* **产出导向：** 为《青少年运动心理策略指南》积累“积极自我对话”章节的丰富素材和具体示例。

# 第三课：运动心理日志：我的内心观察家

* **核心内容：**

* **运动心理日志的目的与价值：** 强调日志不仅仅是简单的记录，更是培养**自我观察、自我反思和自我调节能力**的重要工具。

* **核心观察要素：** 详细指导学生在运动中关注**身体的具体信号**（心跳、呼吸、肌肉酸痛、能量水平）、**情绪的细微变化**（从沮丧到平静，从焦虑到专注）、以及**关键时刻的心理活动**（比如想放弃的念头，或者感到力量爆发的瞬间）。

* **日志记录技巧：** 教授描述性语言的运用（用动词、形容词描绘感受）、**具体化细节**的捕捉（记录发生的时间点、具体场景）、以及**关键词标注**（高光时刻、挑战瞬间）。

* **活动与互动：**

* 老师共享**进阶版《运动心理成长日志》模板**（可为 Google Docs 或 Notion 模板），详细讲解每一部分的填写要求和目的。

* 进行**“情境模拟填写”：** 老师口述一段详细的模拟运动经历（包含身体感受、情绪起伏、小挑战），学生尝试同步填写模板，老师在线指导学生如何“用笔捕捉感受”和记录细节。

* 线上讨论：如何让日志变得生动有趣，而不仅仅是流水账？

* **作业与反思：** 进行 20-30 分钟运动，并根据**详细模板**完成第一篇运动心理日志。重点在于**具体而生动地描述**运动中身体和心理的感受，以及任何闪过的想法。

* **产出导向：** 确保学生能够完成《运动心理成长日志》中内容详实、观察深刻的首篇日志。

# 第四课：面对“撞墙期”：挑战背后的心理学

* **核心内容：**

* **运动中常见的心理挑战类型：** 系统梳理疲劳带来的沮丧、**外界干扰、动力不足、对比心理、害怕失败**等青少年在运动中可能遇到的心理障碍。
○ **心理障碍的初步识别**： 引导学生认识到这些“撞墙期”不仅仅仅是身体问题，更是心理信号。学习识别这些信号的出现。

○ **应对挑战的深化策略**： 回顾并深化积极自我对话在应对具体挑战时的应用，并引入简单的焦点转移技巧（如将注意力从疲劳转移到呼吸节奏、从失误转移到下一个动作）。

* **活动与互动**：

○ 学生线上分享他们日志中遇到的具体挑战；老师引导分析这些挑战背后可能存在的心理因素，例如，为什么一次失误会让人想放弃？

○ “挑战模拟与策略演练”： 老师提出一个常见的运动挑战场景，学生口头尝试运用积极自我对话和焦点转移技巧来应对，老师进行即时反馈和纠正。

* **作业与反思**： 在下次运动中，有意识地记录遇到的**具体挑战类型**，并尝试运用学过的**积极自我对话和焦点转移技巧**应对，详细记录应对过程和策略效果。

* **产出导向**： 丰富《运动心理成长日志》内容，使其包含对挑战的深入分析和应对策略的应用。

### 第五课：我的运动心力量小指南（构思篇）

* **核心内容**： 如何将个人经验转化为可以分享给同伴的策略？《青少年运动心理策略指南》的基本结构和核心信息传达。

* **活动与互动**： 老师展示“青少年运动心理策略指南”的**简化版设计范例**（PPT 或海报设计图），分析其信息组织和视觉呈现方式。引导学生思考他们想分享给朋友的**最重要的 1-2 个策略**（如积极自我对话、如何记录运动感受），以及如何用最简单、最吸引人的方式呈现。

* **作业与反思**： 构思并列出《青少年运动心理策略指南》的 1-2 个核心页面**草稿**（包括主题、关键信息、如何呈现），思考要使用哪些例子。

* **产出导向**： 为《青少年运动心理策略指南》打下清晰的草稿基础。

### 第六课：成果初呈现与回顾

* **核心内容**： 回顾课程所学，初步展示日志和指南草稿，进行双语总结。

* **活动与互动**： 学生线上分享 1-2 篇《运动心理成长日志》中最有感触的片段，**着重阐述如何运用策略应对挑战**；展示《青少年运动心理策略指南》的构思和草稿，**说明为何选择这些策略分享**。老师进行个性化反馈，强调优点并指出改进方向。

* **作业与反思**： 根据老师的反馈，修改和完善日志和指南的初步内容，为下一阶段的深化学习做好准备。

* **产出导向**： 完成《运动心理成长日志》和《青少年运动心理策略指南》的初稿，并对其未来完善方向有清晰认识。

# 2. 进阶级课程方案 (Intermediate Level) rocket icon

### 侧重

深入理解心理策略，提升观察和反思的深度，学习分析运动中的心理模式。
# 概述

本阶段在入门级基础上，引入更具体的心理策略如 SMART 目标设定、基础可视化训练、初步的情绪转化技巧，以及失误后的简单心理复位。日志记录将更加注重对自我心理模式的发现和应对策略的效果评估。学生将开始系统性地构建“青少年运动心理策略指南”。

# 教学目标

*   深入理解并应用 SMART 目标设定和可视化训练。

*   培养更细致的运动观察能力和情绪识别能力。

*   理解焦虑如何影响运动表现，并尝试情绪转化技巧。

*   学习简单的失误后心理复位方法。

*   学会分析运动中的心理模式并记录有效应对策略。

*   提升日志记录的深度和反思的质量。

*   系统性地构建“青少年运动心理策略指南”的框架和内容。

# 课程结构 (Lesson Breakdown) - 线上 1v1 形式

**第一课：运动表现的密码——深入心-体连接与焦虑识别**

*   **核心内容：** 运动心理学基本原理回顾；心流（Flow State）的初步介绍；焦虑如何影响运动表现。

*   **活动与互动：** 学生分享入门级 PBL 的感受和收获；讨论“你何时感觉运动最棒？”引出心流概念。通过小案例（如：比赛前心跳加速、手心出汗）讨论焦虑对表现的影响。

*   **作业与反思：** 观察自己或他人运动中焦虑的迹象，记录在日志中。

*   **产出导向：** 思考《运动心理成长日志》中可深入分析的运动经历。

**第二课：精准出击——SMART 目标设定与情绪转化**

*   **核心内容：** 详细讲解 SMART 原则（Specific, Measurable, Achievable, Relevant, Time-bound）在运动目标设定中的应用；情绪转化技巧（**紧张=兴奋，疼痛=提醒**）。

*   **活动与互动：** 老师提供不同运动场景，引导学生进行 SMART 目标设定练习；通过线上情景模拟，引导学生练习将“紧张”重构为“兴奋”，“疼痛”重构为“身体提醒”。

*   **作业与反思：** 为自己的某项运动设定一个明确的 SMART 目标，并在下次运动时尝试运用情绪转化技巧，记录在日志中。

*   **产出导向：** 为《青少年运动心理策略指南》提供目标设定和情绪转化章节内容。

**第三课：可视化力量与失误后的“下一秒”**

*   **核心内容：** 什么是可视化训练？如何进行基础可视化训练（例如：想象完美完成一个动作，或克服一个障碍）；失误后的心理复位的初步方法（“忘记过去，专注当下”）。

*   **活动与互动：** 老师引导学生进行一次简短的“成功可视化”练习。讨论在球场上/跑道上失误后如何快速调整心态，专注于“下一秒”。

*   **作业与反思：** 在下次运动前尝试可视化训练。如果运动中出现失误，尝试使用“下一秒”复位法，并在日志中记录其对运动表现或心态的影响。
* 产出导向：为《青少年运动心理策略指南》积累可视化和心理复位的范例。

## 第四课：我的运动心理模式分析与应对

* **核心内容**：如何通过日志记录发现自己的运动心理模式（如：何时感到动力十足，何时容易放弃，常见挫折情绪，特定情境下的焦虑表现）。

* **活动与互动**：老师指导学生回顾以往的运动日志，圈出关键词，分析情绪和挑战出现的规律性；讨论如何根据模式调整策略。

* **作业与反思**：选择至少 3 篇日志，尝试分析自己的运动心理模式，并提出 1-2 个新的应对方案。

* **产出导向**：提升《运动心理成长日志》的分析深度。

## 第五课：策略指南的深化与构建

* **核心内容**：《青少年运动心理策略指南》的结构设计、内容组织和语言表达（如何用青少年易懂的语言阐释心理学概念）；选择和组织核心策略。

* **活动与互动**：老师展示不同风格的指南范例；学生构思指南的目录、每个策略（如积极自我对话、SMART 目标、情绪转化、简单复位）的要点和案例，并讨论如何排版设计。

* **作业与反思**：完成《青少年运动心理策略指南》的至少 2-3 个核心策略页面的内容撰写（包括解释、例子和建议）。

* **产出导向**：完善《青少年运动心理策略指南》的详细内容。

## 第六课：成果整合与中期展示

* **核心内容**：将所学知识和实践整合到最终产出中，中期成果展示。

* **活动与互动**：学生线上分享《运动心理成长日志》中分析最深入的篇章；展示《青少年运动心理策略指南》的初步完整框架和部分内容。老师提供详细反馈，指导下一步优化。

* **作业与反思**：根据反馈继续完善两个最终产出。

* **产出导向**：确保两个最终产出都有明确的进度和方向。

# 3. 高阶段课程方案 (Advanced Level) lightbulb icon

### 侧重

综合运用多种心理策略，深入分析复杂情境下的心理调节，提升批判性思维和内容输出的专业度。

### 概述

本阶段旨在培养学生成为运动心理学的实践者和传播者。学生将学习如何结合多种心理策略应对更复杂的运动挑战，批判性地反思策略的有效性，并能以严谨且富有说服力的方式呈现自己的学习成果和见解。最终产出将体现更高的深度、广度和专业度。
# 教学目标

* 综合运用多种运动心理策略应对复杂情境。

* 深入分析结果目标、中段目标、过程目标，并灵活应用。

* 理解巅峰表现的主动与被动（心流 vs. 超常状态）。

* 掌握自我分离技巧等高级情绪调节方法。

* 提升失误后心理复位的深度和效率。

* 批判性反思策略的有效性，能够评估和优化策略。

* 掌握撰写具有深度和说服力的运动心理日志和指南的能力。

* 以专业且吸引人的方式呈现最终产出。

# 课程结构 (Lesson Breakdown) - 线上 1v1 形式

## 第一课：多维目标设定与心智韧性

* **核心内容：** 压力管理与焦虑应对；心理韧性在运动中的重要性；回顾和整合已学策略；结果目标、中段目标、过程目标的深入讲解与应用。

* **活动与互动：** 讨论案例：运动员如何在关键时刻顶住压力？引导学生思考自己在高压情境下的表现和感受。老师引导学生为一项长期的运动挑战（如备战某项比赛或完成一个健身周期）设置全面的三层目标。

* **作业与反思：** 为自己选择的运动挑战设定三层目标，并记录在日志中。

* **产出导向：** 为《运动心理成长日志》提供高压情境分析素材和复杂目标设定案例。

## 第二课：巅峰之境：心流 vs. 超常状态

* **核心内容：** 深入探讨**巅峰表现的主动与被动：心流（let it happen）与超常状态（make it happen）**的区别、特征和触发条件。

* **活动与互动：** 老师分享关于心流和通过主动策略达到超常状态的案例（短视频或文字）。引导学生回顾自己的运动经历，识别是否有过类似“let it happen”或“make it happen”的体验，并讨论如何有意地去创造或捕捉这些状态。

* **作业与反思：** 分析自己一次巅峰表现的经历，尝试区分它是“心流”还是“超常状态”，并记录其关键因素。

* **产出导向：** 为《青少年运动心理策略指南》增加关于巅峰表现的进阶内容。

## 第三课：高级情绪调节与自我分离技巧

* **核心内容：** 深入探讨**自我分离技巧**：**语言转换/切换旁观者视角**（如从“我”到“他/她”），**时间旅行**（“明天的我会怎么看现在？”），**问题重构**（“如果是朋友遇到这个问题，我会怎么帮劝导？”）。

* **活动与互动：** 老师通过情景扮演或案例分析，引导学生练习这些自我分离技巧。学生在线分享练习感受和困惑，老师进行个性化指导。

* **作业与反思：** 针对一次真实的运动挫折或情绪困扰，运用至少两种自我分离技巧进行反思和调节，并在日志中详细记录过程和效果。

* **产出导向：** 丰富《运动心理成长日志》中情绪调节策略的应用，为指南提供高级技巧示例。
# 第四课：策略组合拳与深度心理复位

* **核心内容：** 学习如何将多种心理策略进行有效组合，以应对更复杂的运动挑战；失误后的深度心理复位流程（包括接纳、快速评估、调整焦点和重新投入）。

* **活动与互动：** 老师提供模拟复杂运动场景（如：比赛关键时刻的连续失误、长期伤病复出后的心理障碍），引导学生设计一套完整的“心理应对方案”，包含目标设定、可视化、积极自我对话、情绪转化和深度复位等。

* **作业与反思：** 针对自己一次运动中的复杂挑战，设计并记录一套全面的“心理应对方案”，并在日志中分析其理论基础和预期效果。

* **产出导向：** 为《青少年运动心理策略指南》提供综合策略和深度复位章节。

# 第五课：产出的打磨与精修

* **核心内容：** 最终产出的精修：语言的凝练、排版的专业性、表达的清晰度和吸引力，以及理论与实践结合的深度。

* **活动与互动：** 学生线上分享《运动心理成长日志》和《青少年运动心理策略指南》的最新版本，老师进行细致的语言（包括学术词汇的准确运用、句式多样性）和内容打磨指导。重点关注如何在指南中简洁有效地呈现复杂心理学概念。

* **作业与反思：** 彻底完成两个最终产出的所有内容，并进行最终的校对和润色。

* **产出导向：** 最终完成两个高品质的数字产出。

# 第六课：成果汇报与成长回顾

* **核心内容：** 总结整个 PBL 项目所学，进行正式的成果汇报和深度成长反思。

* **活动与互动：** 学生以“发布会”形式（或模拟 PPT 展示）正式汇报自己的两个 PBL 项目成果，阐述设计理念、主要内容、个人成长和收获。重点强调对复杂心理学概念的理解和应用。老师进行全面评估和最终反馈。

* **作业与反思：** 撰写一份最终 PBL 反思总结报告，回顾整个项目的学习历程、挑战与突破，以及对未来学习和生活的影响。

* **产出导向：** 两个 PBL 最终产出完美呈现，并完成最终反思报告。
