# 未来学者计划
## Future Scholar Program
Thinktown Education

## 项目介绍 INTRODUCTION

Thinktown未来学者项目 (Future Scholar Program) 旨在帮助学生了解并掌握一些常用的化学学科科研知识和方法，通过实践给予学生完整的基础知识讲解、论文/期刊阅读、课题选择、实验设计、论文写作和学术演讲的过程，为未来国际课程项目内对应的论文写作做好铺垫，也给未来的海外大学申请增加学术筹码。

## 适合群体 TARGET STUDENTS

* 国际课程9-12年级学生
* 具备不错的英文读写能力、化学基础知识、实验技能
* 对化学相关方向科研有热情，渴望通过体验化学科研项目证明自己学术能力，获得个人论文产出
