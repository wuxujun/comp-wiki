# 单科学术顾问计划

## PBL 历史旅行指南 · 写作 · 纽约篇

Academic Advising Program — PBL Historical Travel Guide (NYC)

# 一、产品概述

本课程旨在引导学生探索 1920 年代的纽约市，结合历史研究与包括说明文、说服性写作和技术性研究写作，撰写一份富有时代特色的旅行指南。学生将以当时旅行者的视角，深入研究该时期的社会文化、城市风貌及历史背景，并通过精准的描写和叙述，完成一篇 800-1000 字的历史旅行指南，再现那个时代的独特氛围。本课程不仅富有趣味性和探索性，同时促进学生的学术写作能力与批判性思维。通过文献研究、写作反馈等方式，学生将深入理解历史写作的精髓，并锻炼跨学科研究能力。

# 3. 目标客户

本课程非常适合 8-10 年级的学生，尤其是那些对历史充满热情并喜欢通过写作将过去生动呈现的学生。无论是初学者还是有经验的写作者，均适合参与这门课程，帮助他们创作沉浸式的历史叙事和引人入胜的旅行指南。

## 报名要求：

* 年级：8-10 年级

* 英语水平：托福 85-90 分以上或同等水平；在州级英语考试中表现优异。对于分数较低的学生，可根据写作水平进行考虑。

* 写作经验：具备一定的说明文写作基础。

* 投入意愿：每周至少 2 小时课外时间用于写作练习和修改。

# 4. 报名流程

* 写作样本：学生提交一篇原创说明文，最好是来自学生过往历史课程的作品。

* Pretalk：学生与学术顾问进行简短沟通，了解写作经验、目标和课程期待。

# 5. 产品亮点

* 历史沉浸与写作技能：通过创作设定在不同历史时期的引人入胜且富有信息量的旅行指南，将过去生动呈现。

* 研究与真实性：培养从一手和二手资料中获取并整合历史细节的能力。

* 个性化反馈：一对一指导，针对结构、语气和历史准确性提供量身定制的建议。

* 发表机会：将完成的指南分享到个人博客，提交到历史写作竞赛或实际的指南写作公司，或汇编成数字合集。

# 四、常见问题 FAQs

**1. 学生是否需要有任何先前的说明文写作经验才能参加这门课程？**

尽管先前的写作经验可能会有所帮助，但这门课程适合所有写作经验水平的学生，特别是那些有兴趣从历史角度探索纽约市的学生。

**2. 学生是否需要购买任何教材或工具？**

不需要，所有必需的材料和阅读材料都将以数字形式提供。学生只需要带着他们的创造力和学习热情。

**3. 这门课程的时间投入是多少？**

学生应该预期每周花费 1-2 小时在与课程相关的活动上，包括课外的写作练习和作业。

**4. 学生的写作将如何评估？**

学生将收到个性化的反馈，评估重点包括历史准确性与研究质量、描写性和叙事能力、以及组织和清晰度。
