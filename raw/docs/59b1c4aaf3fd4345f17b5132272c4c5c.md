THINKTOWN®
青少年剧作家
独幕剧竞赛
YouthPLAYS
Thinktown Education

简介
INTRODUCTION
YouthPLAYS是一个面向青少年喜剧演员及观众的国际性戏剧作品发表平台，致力于为全球的K-12学校、青少年剧场、戏剧项目、大学等提供优质的戏剧及音乐剧作品。其创办的青少年剧作家独幕剧竞赛旨在鼓励对戏剧感兴趣的青少年进行剧本创作。

推荐理由
ADVANTAGES
对主题和篇幅的限制较少，学生有较多发挥空间
致力打造全美最为完善的青少年文本题材中心，包容性强，题材不限

赛事亮点
HIGHLIGHTS
主题聚焦青少年，官网特别鼓励以青少年生活为题材的剧本，引发共鸣和思考
所有参赛作品将由经验丰富的戏剧专业人士进行评审

参赛对象
TARGET STUDENTS
面向美国和国际的青少年剧作家，19岁以下的学生

参赛要求
FORMAT AND TYPE
剧本应为原创作品，即参赛之前未曾出版或公开演出
剧本类型为独幕剧，时长控制在45分钟以内（大概在20页左右）
剧本内容应适合青少年观众，避免涉及敏感或暴力题材
剧本需符合 YouthPLAYS 的格式要求，具体格式可参考官网。除剧本外，文档中还需包括标题页和角色列表
必须登录 YouthPLAYS 官网，在线提交完整剧本。不能通过邮件或纸质形式提交作品。

报名开始时间：
2025年1月1日

奖项设置
SETTINGS
冠军获奖者将获得 $250 的奖金和作品在YouthPLAYS出版的机会
亚军则可以获得 $100 的奖金
