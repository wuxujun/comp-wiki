# 070925 PBL Syllabus & Curriculum-经济学科 from wcl

《直播打游戏如何赚钱？流量变现机制解析》

**Level 1 (TOEFL 60) | 基础课程：入门理解 + 简单表达 + 图文结合**

**Session 1：什么是游戏直播？**

学习目标：了解游戏直播的基本定义、常见平台（如 Twitch、YouTube、抖音, Bilibli, 斗鱼）以及主播和观众的基本角色。

学生活动：用英文介绍一位自己知道的游戏主播，并写出三项他/她做的事情（玩游戏、聊天、带货等）。

**Session 2：主播怎么赚钱？**

学习目标：理解打赏、平台分成、广告、带货等主要变现方式的基础概念。

学生活动：绘制一张收入构成图，用图标和关键词表示每种收入来源。

**Session 3：观众为什么喜欢看直播？**

学习目标：分析观看动机（放松、学习技术、参与互动等），引导学生观察用户行为背后的心理动因。

学生活动：完成一张“我为什么看直播”理由卡片，用英文写出至少三个理由。

**Session 4：情绪和打赏有什么关系？**

学习目标：通过实例视频理解情绪高涨与打赏之间的联系，建立“行为—反应”初步模型。

学生活动：模拟观众打赏行为，用表情贴纸和英文短句描述直播中的情绪反应。

**Session 5：简单分析一位主播**

学习目标：练习用英文描述一个主播的直播内容、粉丝数量和收入来源，理解信息整理的基本方法。

学生活动：完成一张主播小档案卡，并写一句话总结“为什么他/她赚钱”。
**Session 6：图表初体验：主播收入图**

学习目标：认识条形图、饼图等基本形式，并尝试用数据表达比例。

学生活动：用模板完成一张收入构成图，并写一句总结（e.g. Most of the money comes from…）。

**Session 7：我如果当主播？**

学习目标：鼓励学生以第一人称设想直播内容，表达兴趣与规划，构建简单假设句型。

学生活动：填写“我的直播频道”卡片，包括内容、目标观众、预期收入等。

**Session 8：成果展示：我的直播计划**

学习目标：整合所学词汇与结构，完成简短的图文展示与口头表达。

学生活动：展示直播卡片，进行 1 分钟英文介绍练习，可选录制视频。

# Level 2（TOEFL 80）｜进阶课程：模型拆解 + 平台比较 + 商业结构表达

**Session 1：直播的赚钱逻辑**

学习目标：理解“内容-流量-变现”的三步路径，初步构建直播经济链模型。

学生活动：绘制自己的流量变现模型图，并用 3 个句子解释路径（内容 → 流量 → 收入）。

**Session 2：我研究的主播如何赚钱？**

学习目标：通过调研资料（文章/短视频），分类主播收入来源及占比。

学生活动：整理一份主播收入结构表格，用英文说明每一项收入所占比例。

**Session 3：平台规则对收入有什么影响？**

学习目标：了解不同直播平台的政策差异（如 Twitch vs 抖音），思考对创作者的影响。

学生活动：完成对比图，并用英文写出两个平台的不同点及影响。

**Session 4：观众行为与打赏动机分析**

学习目标：初步引入用户行为心理模型，观察主播与观众的互动模式。

学生活动：完成一份“观众行为分析卡”，描述一个常见打赏动机与对应行为。

**Session 5：可视化数据与解释练习**

学习目标：使用图表辅助表达收入结构或观众行为分布，训练图文结合的输出能力。
学生活动：制作一张图表，并撰写一段英文说明（不少于 70 词）。

**Session 6：主播商业模型整合**

学习目标：综合运用已学内容，建立完整的主播商业运营路径图。

学生活动：制作“某主播商业模型图”，包括内容、流量、平台、收入与用户反馈等要素。

**Session 7：演讲准备：我的研究计划**

学习目标：构建结构清晰的演讲稿，包括问题陈述、案例分析、总结观点。

学生活动：练习 2 分钟英文演讲，进行小组内试讲并获得反馈。

**Session 8：成果展示：我的主播经济研究**

学习目标：展示学生商业逻辑、图表表达与口语表达的综合能力。

学生活动：进行正式演讲，展示 PPT（2 页：模型图 + 分析结论），参与评分与互评。

# Level 3（TOEFL 100）｜高阶课程：行为心理 + 商业模式 + 观点演讲

**Session 1：什么让主播成功？**

学习目标：拆解一个成功主播的运营逻辑，识别关键要素（内容风格、平台策略、用户粘性、创收组合等）。

学生活动：分析一位成功主播案例，完成一张“成功要素拆解图”。

**Session 2：流量与收益之间的转换逻辑**

学习目标：构建“流量转化路径图”，理解粉丝增长、活跃度与付费行为之间的关系。

学生活动：绘制一张完整的流量变现逻辑图，并用英文写一段说明文。

**Session 3：观众行为背后的心理机制**

学习目标：学习基础行为心理学理论（如“即时奖励”“情绪驱动”“沉浸机制”）与直播互动结合。

学生活动：制作“观众心理模型卡”，列出 3 种常见心理机制与相应主播策略。

**Session 4：收入结构精细化分析**

学习目标：分析主播收入来源的比例、稳定性与增长潜力，理解“主副线收入”的构成。

学生活动：制作主播收入结构分布图，并用英文写作一篇收入解构说明文。

**Session 5：从数据到论证：完整的商业逻辑构建**

学习目标：整合数据图表、心理行为与平台特征，构建商业论证的核心逻辑链。

学生活动：撰写一篇完整分析稿（Introduction-Evidence-Discussion-Conclusion）并准备
演讲草稿。

## Session 6：演讲风格与结构训练

学习目标：提升表达的逻辑性与表现力，掌握 TED 式演讲结构（开场–故事–分析–收束）。

学生活动：练习 3 分钟演讲，重点训练语速、停顿、句式变换与视觉配合。

## Session 7：个性化商业展示排练

学习目标：结合个人兴趣和风格，展示一套属于自己的内容创作/直播变现设计方案。

学生活动：进行个性化商业展示排练，获得同伴反馈并优化稿件与图表。

## Session 8：最终成果展示：我如何成为下一位成功的数字创作者？

学习目标：完整输出“我的商业模型与盈利逻辑”，体现多角度思维与专业表达。

学生活动：正式演讲展示（含 PPT 与 Q&A），提交英文分析报告。

# 《虚拟情境消费行为分析》

## Level 1（TOEFL 60）｜基础课程：购物表达 + 情境体验 + 简单心理词汇

### Session 1：什么是“虚拟购物”？

* 学习目标：了解虚拟情境（模拟电商、游戏商城等）的概念，激发学生对消费行为的兴趣。

* 学生活动：列出自己最近一次线上购物经历，并画出“我的购物路径”（想买→浏览→下单）。

### Session 2：我都买了什么？为什么买？

* 学习目标：学习描述购物物品与消费动机（I bought... because...），并初步引入“想要 vs 需要”的概念。

* 学生活动：完成一张购物清单卡片，并用简单英文写出每件物品的购买理由。

### Session 3：我喜欢什么样的购物页面？

* 学习目标：认识购物页面的基本元素（图片、价格、按钮），分析“视觉影响”对决策的
作用。

* 学生活动：看两张购物页面截图，打分并表达哪一张更吸引人，为什么。

**Session 4：虚拟盲盒实验室**

* 学习目标：模拟“抽卡/盲盒”情境，观察学生的选择过程与情绪变化，初步识别“期待”“失望”等购物相关情绪词。

* 学生活动：每人体验一次“虚拟盲盒”，记录打开前/后的感受，并用词卡表达情绪。

**Session 5：我的虚拟消费偏好分析**

* 学习目标：回顾购物记录，尝试分类并解释“我买得最多的类型”，并初步建立“偏好”一词的表达。

* 学生活动：制作一张“我最常买的三种商品”饼图，并写一句总结性分析。

**Session 6：我看到、我想要、我买了——购物流程图**

* 学习目标：梳理购物决策链条，认识影响消费行为的多个环节（广告、朋友、情绪等）。

* 学生活动：完成一张“我的购物流程图”，并用简单句配图解说。

**Session 7：我的虚拟购物日志**

* 学习目标：整合购物词汇、流程表达与情绪词，完成一篇英文观察日记。

* 学生活动：写一段英文小文“My Shopping Story”，讲述一次虚拟消费体验。

**Session 8：展示我理解的购物心理**

* 学习目标：通过展示卡片与口头表达，说明学生对虚拟消费行为的初步理解。

* 学生活动：展示购物流程图或日志卡片，进行 1 分钟英文介绍。

# Level 2（TOEFL 80）｜进阶课程：偏好分析 + 数据整理 + 简单心理标签运用

**Session 1：什么影响了我的选择？**

* 学习目标：通过模拟购物平台操作，引导学生关注“推荐机制”“评论”等外部影响因素。

* 学生活动：列出 5 条影响购物决策的因素（价格、包装、评分、朋友推荐等），并写出一条英文解释。

**Session 2：为什么我更喜欢买 A 而不是 B？**
*   学习目标：建立比较句型（prefer, more attractive than...）并引导学生描述自己购物偏好的形成逻辑。

*   学生活动：选择两件商品，用一段英文比较说明“我为什么选了这一个”。

## Session 3：我的“数字足迹”都透露了什么？

*   学习目标：初步了解平台如何记录与分析消费者数据，感知“数据行为”的存在。

*   学生活动：模拟填写平台浏览/购买记录，并观察分析其中的偏好模式。

## Session 4：虚拟消费背后的常见心理

*   学习目标：介绍 3–4 个基本消费心理动因（如 FOMO、即时满足、稀缺感），引导学生与自身购物经历对照。

*   学生活动：完成“我经历过哪种心理”打卡表，并举例描述一个具体场景。

## Session 5：情绪与消费：购物真的让我开心了吗？

*   学习目标：理解“购物带来短暂愉悦”的心理机制，并尝试对比“期待值”与“满意度”。

*   学生活动：完成一次虚拟购物体验后打分（开心程度+满意程度），写一句话分析。

## Session 6：可视化我的购物心理行为结构

*   学习目标：尝试将自己的一次购物行为用流程+心理+结果的方式图像化表达。

*   学生活动：绘制一张“我的购物行为结构图”，包括：起点 → 诱因 → 情绪 → 选择 → 结果。

## Session 7：撰写购物行为说明文

*   学习目标：使用结构化语言（首先… 然后… 最后…）总结一次虚拟购物行为及心理分析。

*   学生活动：撰写一篇英文短文“My Digital Shopping Mind”，不少于 100 词。

## Session 8：成果展示：我是购物心理小研究员

*   学习目标：展示自己的购物偏好、心理过程与行为图表，提升表达能力与反思深度。

*   学生活动：进行英文展示（图表+说明文摘要），参与组内互评与反馈。

# Level 3 (TOEFL 100) | 高阶课程：多因变量分析 + 消费心理建模 + 观点输出

## Session 1：什么是“消费决策”？
* 学习目标：构建虚拟消费行为中的决策结构，识别多重变量（价格、社群影响、诱导机制、风险回避等）。

* 学生活动：绘制“虚拟消费决策要素图”，列出 5 个以上变量，并说明变量间可能的关联。

## Session 2：从盲盒到氪金：即时满足背后的心理机制

* 学习目标：引入即时满足、预期落差、行为强化等心理概念，讨论其在青少年常见消费行为中的体现。

* 学生活动：撰写案例简析：“一次我为了感觉好而消费的经历”，并配心理术语解释。

## Session 3：数据化我自己的消费行为模型

* 学习目标：使用数据采样和偏好记录工具（如模拟表格），形成学生个人的消费行为数据样本。

* 学生活动：完成“7 日虚拟消费观察表”，并用柱状图或折线图可视化行为变化趋势。

## Session 4：同一产品，不同人为什么会做出不同选择？

* 学习目标：引导学生探讨消费选择中的个体差异（认知风格、情绪倾向、社交背景），强化分析与推理。

* 学生活动：阅读对比案例，撰写短文：Why would I choose differently from someone else?

## Session 5：构建我的“虚拟消费心理模型”

* 学习目标：整合动因、行为、反馈三维，建立个人消费心理路径图，并准备图文表达。

* 学生活动：制作“我的消费心理流程图”，并用英文关键词注释每一环节。

## Session 6：观点表达训练：虚拟消费对青少年的影响

* 学习目标：从个体经验出发，撰写带有个人视角与事实支持的英文观点短文。

* 学生活动：写一篇英文文章（约 150 词）：“Is Virtual Spending Good or Bad for Us?”

## Session 7：演讲准备 + 视觉材料完善

* 学习目标：组织多模态展示材料（流程图+案例分析+观点），形成完整的口头表达方案。

* 学生活动：完成 PPT 设计 + 练习 3 分钟英文展示，准备观众提问回应。

## Session 8：最终成果展示：我是数字消费心理研究者

* 学习目标：以研究者身份完成整合性展示，反映学生的认知深度、表达能力与思辨视角。
角。

* 学生活动：正式演讲展示（含流程图、模型与观点），参与评议与小组回馈。
