# 导演手札
# Director's Notebook

Illustration of a Director's Notebook showing sections for Adaptation Concept, Character Analysis, and Stage Visual Design

<mark>6课时(CT) + 1课时(NCT)</mark>

## 项目简介

本项目是一项结合了戏剧研究和创意设计的项目制学习课程，学生不仅会去“理解人物”，更将学习如何拆解并完成一个图文创意作品产出（导演手札）。学生将从导演与戏剧学者的双重视角出发，分析人物的动机、语言特征、内在冲突与社会背景。研究对象不设限制，可以来自戏剧、文学、影视、历史，甚至现实公众人物。通过文本精读、调研与分析，学生将学习导演视角的形成和具体的戏剧设计技能，为角色的行为方式与舞台呈现进行一个完整的设计展示。

## 适合学员

- 正备战国际学校、美高或美本申请的学生

- 意向戏剧、文学、历史、社科或人文方向

- 缺少可视化项目，希望通过该项目展现创意、文本理解力和分析能力的学生

## 课程安排

<mark>三大模块，7节课完成一个完整项目：</mark>

* **剧本分析：**拆解角色台词、冲突与动机

* **导演视角训练：**理解表演、灯光、服装与舞台设计

* **项目产出：**完成展示、获得反馈并打磨定稿

## 项目产出

Notebook icon

### 导演手札

改编概念、人物深度解析、舞台视觉设计方案。作品可直接作为大学/美高申请的 Writing Sample 附件或上传至个人学术网站！
