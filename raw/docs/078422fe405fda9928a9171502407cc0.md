# 

每年7-8月，大量家庭开始为新一轮的申请季或商赛季做准备。

尤其对于意向财经商方向的学生来说，暑假是非常宝贵的“战略规划期”。

📌 家长们常常有这样的疑问：

哪些比赛适合学生现阶段的水平？

是不是只有高年级才能开始接触财经商类内容？

不同赛事到底含金量差距有多大？

暑期的学习备考任务繁杂，如何有效规划，才能获得学术积累？

这篇文章，我们将从目标导向出发，为你梳理不同阶段、不同目标学生适合的财经商类活动与准备方式，帮助你找到最适合的起点，并明确行动时间线。

冲击奖项？

主流赛事要从暑假就开始布局

系统积累？

暑期是“静心打基础”的黄金期

1

设计思维

以斯坦福大学设计思维为主题，面向6-12年级学生开放
