# 

说到高含金量的化学竞赛，一定绕不开UKChO英国化学奥林匹克竞赛。英国G5和美国前30的院校都接受UKChO成绩，剑桥大学更是直接点名UKChO，在官网上推荐学生积极参与，鼓励学生借此强化化学思维和能力。

不过我们也了解到，很多同学由于考试时间和考试难度，不得不放弃UKChO。

那么，是否还有被顶尖院校视为化学能力标尺的其他竞赛，供同学们选择呢？

今天给大家介绍一个由剑桥大学化学系和圣凯瑟琳学院共同主办的全球性高中生化学挑战，也是剑桥大学校方正式推荐的高中生精品学术项目：剑桥化学挑战（Cambridge Chemistry Challenge Lower 6th）C3L6。

比赛推荐理由

1、更注重深度理解和应用 

C3L6相比较于UKChO更注重促进中学生对化学科学深层次的理解及其在现实世界中的应用。

C3L6竞赛旨在激发学生对于科学探究的热情，提高他们的独立思考和问题解决能力。这对于准备进入大学学习STEM相关专业的学生来说尤其重要。

2、辅助校内化学课程学习 

C3L6考察范围是A-Level化学知识点，并在其基础上拓展延伸，因此想要获得好成绩，务必先掌握在校学习的A-Level化学知识，对于A-level的同学来说，参赛既能复习，又能冲奖。

3、含金量高 

C3L6由剑桥大学组织举办，常被用于UKChO的预选和前置测评，也正因如此，很多英国顶级学校将C3L6作为衡量申请者的化学学术能力的标尺。

C3L6比赛信息

参赛资格：9-11年级

建议有一定的化学知识基础，需要一定的科学阅读能力，

考试时间：2024年6月5日（周三）17:00-18:30（90分钟）

报名截止时间：5月24日

考试形式：个人形式，90分钟，试卷由2-3个问题组成。给定2-3个大的化学主题，每个主题下面包含十几个由浅入深的相关小问题。

考察范围：A-Level化学知识点，并在其基础上拓展延伸

奖项：

Roentgenium Award 特等奖

Gold Award 金奖

Silver Award 银奖

Copper Award 铜奖

C3L6备考锦囊

01

C3L6的难度别小瞧

虽然考试涉及的题量以及每题的难度都比UKChO要简单一些。

图｜C3L6往年真题

但是从内容的难度来分析，对于大部分的高中生都还是有一定的挑战的，尤其是对于高一/IG阶段的学生，目前还是有较多的内容没有接触过。

02

来看看C3L6的复习技巧

1.全面学习考试涉及知识点是最关键的部分，如果知识点背景不了解，基本题目就完全没办法完成；

2. 考试难题部分都不是直接考察知识点，尤其是结合有机部分，对应的应试技巧也是必须要掌握的；

3. 比赛获奖比较容易，只需要25%左右的正确率即可，但是要想获得金奖及以上难度还是比较大的，合适的答题策略也是非常重要的；

图｜2023年分数线

4. 考试全部都是问答题，且问题比较综合，也会结合一定的当下热点，需要通过练习适应对应的考察方式。
