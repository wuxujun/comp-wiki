# CBPA 2027 初级站报名指南

## 活动简介

CBPA 未来商业领袖研习社（China Business Professional Alliance）是专为中学生提供的商业实践研习平台，也是中国区唯一通往全美三大商业研习活动 BPA 全球站的活动。CBPA 学术标准与荣誉互认机构 BPA 获得 CTSO 生涯规划教育协会认证，是 AP 官方推荐商科研习活动，也是 AP Business with Personal Finance 课程官方推荐的商业教育合作伙伴中，唯一落地中国、为中国学生开放直接报名通道的国际商科研习项目。

CBPA 旨在通过真实行业课题、多元实践项目体验、严谨的学科知识体系、同好朋辈交流，为同学们提供链接真实商业世界、链接学界业界菁英网络，培养中学生全球化的商业思维、视野与综合素养，提升学生的领导力、专业职业素养和真实商业问题分析与解决的能力。自引入中国以来，每年参与学生超 45,000 名，全球范围内认证俱乐部超 1,800 个。在与微软、惠普、谷歌等国际 500 强企业合作中，参与学生的真实商业实践背提履历和能力备受赞誉，也为学生提供了探索多种方向的可能性和人生选择。

CBPA 2027 活动季已于 2026 年 6月正式启动暑期报名，有关初级站研习阶段报名流程展示如下：

**附件 1：常见问题解答**

**Q：S-Classic 组别中，年度主题和自定义主题只能选一个吗？**

A：是的，今年参与的小队可以在建议主题「二次元消费主题」、「潮流运动主题」、「AI 主题」中选择，若小队有自己的创意和想法，也可以自由选题。

**Q：S-Pre 和 ML 组别是否可选自定义主题？**

A：可以的，今年各个组别都可以自由选择主题或自定义主题。

**Q：S-Classic 组别中，选择年度主题和自定义主题的团队所获荣誉如何评定？**

A：在 S-Classic 组别，选择年度主题和自定义主题的团队所获荣誉将分别评定，团队在各自选择的主题类别内进行评选。

**Q：ML 组别中，使用中文是否可进阶三轮研习活动？**

A：在 ML 组别中，任意轮次（含初级站和中国站）使用中文，都不可进阶三轮（含 BPA(U.S.)和 BPA(ASIA) x WYF Championship）。

**Q：选择 S-Pre 组别是否可进阶三轮研习活动？**

A：选择 S-Pre 组别，不可进阶三轮（含 BPA(U.S.)和 BPA(ASIA)）。

**Q：除语言区别外，S-Classic 和 S-Pre 以及 ML 的区别还有什么？**

A：S-Pre 和 ML 组别除可使用中文外，作品产出的难度（例如：财务分析板块的要求）低于 S-Classic 组别。

**Q：CBPA 2027 初级站的发票如何申请？**

A：初级站报名费用默认发票类型为电子增值税普通发票，默认发票内容为活动费，如需发票，请等初级站活动结束后，前往 Bloom 缴费界面申请开票。
**附件 2：组别介绍**

## 01 Academic Based Division

- **年级要求**：G9-12
- **参与形式**：个人商业基础能力测评，市场营销与商业管理的综合知识考察
- **内容涵盖**：市场营销、商业模型、人力资源管理、市场调研等
- **考核形式**：客观题测评

\*初级站不区分市场营销和商业管理两个方向

## 02 Project Based Division-ML

- **年级要求**：G6-9
- **参与形式**：团队（3-4人）
- **考核内容**：团队商业路演测评，团队成员分工合作，从不同商业角色的视角出发针对年度主题案例进行分析，产出一份商业方案，最终通过幻灯片及演讲的形式展示成果。
- **考核形式**：商业案例分析，产出商业方案。任务难度低于 S-Pre 组别，可使用中/英文，任意轮次使用中文无法进阶全球站研习阶段。

## 03 Project Based Division-S Pre

- **年级要求**：G9-12
- **参与形式**：团队（3-4人）
- **考核内容**：团队商业路演测评，团队成员分工合作，从不同商业角色的视角出发针对年度主题案例进行分析，产出一份商业方案，最终通过幻灯片及演讲的形式展示成果。
- **考核形式**：商业案例分析，产出商业方案。该组别为中文组别，难度低于 S-Classic 组别，该组别无法进阶全球站研习阶段。

## 04 Project Based Division-S Classic

- **年级要求**：G9-12
- **参与形式**：团队（3-4人）
- **考核内容**：团队商业路演测评，团队成员分工合作，从不同商业角色的视角出发针对年度主题案例进行分析，产出一份商业方案，最终通过幻灯片及演讲的形式展示成果。
- **考核形式**：商业案例分析，产出商业方案。该组别仅可使用英文。

\*全部组别组队不限年级、学校、城市、地区
