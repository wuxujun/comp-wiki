# 海洋意识竞赛

Bow Seat Ocean Awareness Contest

竞赛难度 ☆☆☆☆☆

Thinktown Education

## 课程简介 COURSE INTRODUCTION

海洋意识竞赛是由美国环境保护NGO组织Bow Seat主办的比赛，是一个让年轻人通过艺术创作和创意交流来了解环境问题，探索他们与不断变化的世界的关系，并成为积极变化的倡导者的平台。

> **竞赛主题 - “你的故事，我们的海洋”**
> 你与海洋的个人联系，以及海洋为你的生活带来的价值
> (截止日期：2026年6月8日)

## 参赛类型 TYPE

* 创意写作、绘画、摄影、雕塑、装置、综合媒介、平面设计、网页设计、APP设计、音乐改编、歌曲创作、电影等
