# 

IA（internal assessment）是广大IB学子必经的一道坎，其得分占IB总成绩的20%。IA的考查方式与同学们熟悉的知识点考试有很大不同，需要同学们独自进行一项研究，最终提交一份研究报告，老师将根据报告撰写内容进行评分。

由于同学们较少进行此类课题研究，IA想拿高分并不容易。那么，在IA的实施过程中，要注意避免哪些“坑”呢？今天，我们将结合过往同学的案例和大家分享~

不做“DDL战神”

IA相对于知识点类型的作业而言，需要的时间和精力都会比较多，不能像其他作业一样，拖到DDL才开始动手。小编在工作中经常会遇见明天要交任务了，今天才开始动手的同学，在时间如此紧张的情况下，一般很难得到高分。

不做调查研究就直接上手

IB-IA属于开放类课题研究，并没有固定的知识范围，并且学生要想得高分，必须得有超越课本难度的内容。因此课题的调查研究十分关键，需要同学们在熟悉基础概念的基础上，查阅资料整理之后，做到心中有数，然后再进行实验安排，否则实验中遇到问题就会手忙脚乱，甚至可能实验失败。

报告匆匆搞完，不经修改就直接提交

对于一般的题目而言，只要你知识点会，写完题目就可以交作业，但IA不一样，它是一篇小论文，需要经过多轮的修改后才能有比较高的质量。

新课堂H同学在复盘时发现，报告内容其实问题不大，但由于报告写完没有进行修改，格式部分问题很大，在communication部分丢分严重，最终导致得分偏低。

上面的提到的一些“坑”，同学们有没有踩中呢？

对于化学IBer而言，IA创作的过程中还可能遇到这些问题：

👉 不知如何开题？

👉 想了许久的题目但却没有研究意义？

👉 试验方法不知如何改进？

👉 无法获取可靠、准确的试验数据？

👉 文章内容结构混乱缺乏逻辑？

我们不难发现，从选题、试验到报告撰写都需要有专业的理论知识基础，仅凭兴趣缺乏方法是无法做好研究的，同学们可以寻求专业老师的指导，更有可能产出高质量、严谨而富有学术价值的报告，拿到一个不错的分数。

大家也可以参加新课堂的未来学者项目（Future Scholar Program），在老师的指导下，系统学习科研基础知识、期刊/文献阅读方式、课题选择、实验数据与数据获取方式、实验数据分析、标准科研论文写作和学术演讲等技能，最终完成学术产出，展现学术实力。
