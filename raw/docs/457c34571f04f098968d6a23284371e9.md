简介
INTRODUCTION
普林斯顿大学十分钟剧本竞赛是一项面向美国及国际同等学
年的高二学生(11年级)举办的年度赛事。该竞赛旨在鼓励学生
创作原创剧本，并为他们提供一个展示才华的平台。比赛每
年邀请知名剧作家担任评委，对参赛作品进行评选。
推荐理由
ADVANTAGES
■ 含金量高，由普林斯顿大学主办，知名剧作家担任评
委，获奖作品将获得广泛认可和关注
参赛要求
FORMAT AND TYPE
■ 学生需要线上提交不超过10页的原创英文剧本，每页
相当于1分钟表演时长。
■ 题材不做特定限制，可参考的类型包括但不限于：现
实主义、荒诞主义、喜剧、悲剧、音乐剧等
报名截止日期
DEADLINE
★ 具体截止日期不定，但通常设置在在4-5月
★ 每年收集满250份参赛作品时，官方将关闭报名通道。
