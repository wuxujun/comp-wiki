# 03 规划建议时间轴

**6-7年级 探索阶段**

**8-9年级 练习阶段**

**10-11年级 聚焦阶段**

**11-12年级 冲刺阶段**

**\*创意写作**

可从兴趣出发，尝试探索不同类型的符合年龄要求的初级竞赛，例如社会公正奖Junior组，了解、判断英文写作是否适合自己。

可结合个人写作短板及提升需求，选择特定文体的中级竞赛，例如纽约时报评论比赛、哈佛深红报全球征文大赛，以赛代练，提升写作能力。

可结合个人学术兴趣及意向专业，选择对标的中级及高级竞赛，例如纽约时报公开信写作比赛、社会公正奖，通过选题进行专业探索，展现学术兴趣及能力。

基于此前的经验积累，可选择学术性较强、含金量较高，或是相对获奖率稍高的赛事，例如哈佛国际评论学术写作比赛，作为申请阶段最后冲刺。

无既定规划路线，可根据学生个人兴趣、创意想法、写作经验、作品积累等，个性化定制创作、投稿、专业级赛事参赛计划。

# 04 辅导模式

**学术顾问计划**

**学科类咨询课程 (ABC课程)**

1v1全程辅导，包含标准辅导模块及标准服务时长，形式可包括实时互动 (CT)，例如授课讨论，与非实时互动 (NCT)，例如文章修改反馈。

无标准课时，根据学生具体情况制定个性化课程安排，形式可包括实时互动 (CT)，例如授课讨论，与非实时互动 (NCT)，例如文章修改反馈。
