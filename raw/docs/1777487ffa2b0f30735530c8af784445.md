# 

2026年3月，第十四届CTB全国论坛圆满落幕。

在这场汇聚了全国近2000支优秀青年研究团队的顶尖学术盛宴中，Thinktown的6支队伍凭借扎实的学术功底和深刻的社会洞察，不仅实现了100%荣获区域/全国荣誉的壮举，更有3支队伍成功突围，锁定哈佛全球论坛的入场券！

这些课题涵盖社会关怀、家庭教育、健康创新、环境科学、青少年发展等多个维度——从服务业的夜班工作者到双职工夹心层父母，从健身人群的营养补给到亲子沟通新路径，从废弃口罩微塑料到青少年社交盲盒——每一个项目都是对“立大志，做小事”的最佳诠释。

让我们一同回顾这场思维碰撞的荣耀之旅。

硬核战果：不止于晋级，更是学术实力的认证

根据CTB官方论坛发布的荣誉标准，奖项的含金量直接对应着在全国论坛中的排名百分比。

在竞争尤为激烈的2025-2026赛季，Thinktown学子交出了一份亮眼的成绩单：

TOP 5-20%·全国论坛二等荣誉暨全球论坛入围： 

3支队伍凭借严谨的学术研究与创新的解决方案，荣获此项殊荣，直接晋级哈佛全球论坛。

他们的课题涵盖了社会行为与经济、生命科学与健康等多个高难度学科领域。

TOP 20-50%·全国论坛会议期刊发表：

2支队伍的研究成果因其学术价值被官方认可，收录于CTB全国论坛会议期刊，达到了发表级别。

区域荣誉：

1支队伍获得华东区域团队三等奖，展现了在特定区域的强劲实力。

这意味着，Thinktown的每一支入围队伍都在全国舞台上留下了属于自己的印记，其中50%的队伍达到了代表中国区顶尖水平的全球论坛晋级线。

全球展望：下一站，哈佛！

历年战绩回顾：深耕 CTB，我们从未止步

从2022年至今，新课堂在 CTB的舞台上始终保持着令人瞩目的竞技水平。

连续四年，我们累计助力23支小队、124名学子在全国论坛脱颖而出，并成功输送13支核心团队晋级全球赛。

2023-2024赛季，我们以5支全国获奖队伍实现了80%的全球赛晋级率，展现了极强的项目转化力；

2024-2025赛季，我们迎来人数爆发，35名学子集体闪耀全国论坛，创下历年获奖人数之最；

2025-2026赛季，在竞争愈发激烈的全球赛选拔中，我们依然稳占3席全球赛名额，延续了顶尖学术机构的强势地位。

写在最后-关于CTB

CTB全球青年研究创新论坛(简称CTB)源自哈佛大学"HarvardThinksBig"，是世界范围极具影响力的华人青少年跨学科学术研究项目。

十多年来，数万高中生天马行空的想法在这里生根发芽，通过长期的研究学习和团队协作，不断增强其落地可行性和科学严谨性，持续检验和改进项目成果，最终以论文和报告的形式记录自己的创新发现和实践成果。

CTB历届获奖者中曾走出数百位哈佛耶鲁等常春藤级世界名校录取者、多位省市高考状元、数千位世界知名学府和国内顶尖高校录取者。
