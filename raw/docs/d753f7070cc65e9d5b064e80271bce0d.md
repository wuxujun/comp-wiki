# 

有很多同学，一直非常热爱画画，但大学想读非艺术专业。

而对于很多美国大学而言，这样的学生，有着多方面的创造力，和将艺术与非艺术学科结合的潜力，而且思维也会更灵活。

新课堂的袁同学，在2022年春季参加了新课堂艺术科的少美联赛辅导，以《鲸鱼的守护》获得了少美联赛的大师赛三等奖，这幅画讲的是鲸鱼和女娲的故事，鲸鱼来体验人间，陪伴女娲，离别时依依不舍，最后，鲸鱼恳求女娲在它的背上造了一个新的世界。

她是一位非常热爱画画的艺术家，而同时，她想要在大学读心理学的方向。

袁同学获奖作品《鲸鱼的守护》

2022年获少美联赛大师赛三等奖

辅导她参加少美联赛的章老师章老师觉得她的经历，可以给到很多热爱画画但想申请非艺术学科的同学，一些有趣又宝贵的启发，所以进行了采访。

【章老师】你是从什么时候开始画画的？

【袁同学】小时候一直在画，喜欢画人。后来五六年级的时候去学过漫画，那时画的东西就多了起来，比如漫画的女生。小时候我特别喜欢漫画。后来进了国际学校，能有时间让我去画画，所以就开始系统地学画画。

【章老师】你说过想大学读心理学方向，那你怎么看待心理学和画画之间的联系呢？

【袁同学】对于心理学，我比较感兴趣人与人之间的关系和交流。学心理学时，课上会有提问和讨论，和大家一起聊，也要发表自己的想法。但画画是一个人自己静下心来做自己的事情。

而如果我长时间跟一群人在一起，不停地听大家的想法、表达自己的想法，完全没有独处的时间，就会感觉累；但是一直独自做自己的事情，又会有点孤单。所以，学心理学和画画的两种状态，会形成平衡。

【章老师】你说对心理学的人际交流感兴趣，那么你会喜欢画和人与人交流有关的题材吗？

【袁同学】会，因为我会把人物画成有小故事的小漫画，这样会有更丰富、更有意思。

【章老师】在学习很忙的时候，你怎么平衡画画的爱好和自己的学业？

【袁同学】我会在学习了一两个小时后，比如学完了一个英文的系列后，在休息的时候画一会儿，再开始学下一门学科。这时，我会画可爱的小图案。

我平常会写日记、画日记画，本子上有空白页，不可能整篇都写满，我就喜欢在上面画一些小东西，比如我今天到品尝到了很好吃、很好喝的东西，我就会把它以绘画形式记在自己的本子上面，从而满足我画画的那种欲望。

【章老师】艺术会不会对你的学习有帮助？

【袁同学】画画了以后，我可以坐很长时间去静下心来做一件事情。而且，画画可以释放压力，在压力大的时候画一段时间，我就感觉重新有了动力。

【章老师】可以回忆一下，当时画这幅参加少美联赛的画，有什么感觉吗？

【袁同学】这幅画是以大海作为主题的。我家住在海边，出小区后走半个小时就能看到海，从小经常在海边玩，一家人也经常在海边散步，我很喜欢大海。它很宽阔，有自由的感觉。而且我本身很喜欢蓝色和紫色。

【章老师】在新课堂的艺术竞赛辅导印象最深刻的地方？

【袁同学】在竞赛辅导之前，我画画通常是画照片，或者是临摹一幅画，很少有在定了一个主题以后，去了解各种各样的形式、画风，进行更多尝试，然后找到自己喜欢的。

而且，老师会与我讨论画面的意义，让我更了解我的画。以前我画画只是因为好看，或者想如何去临摹，怎么把它画出来，但不常去了解一幅画背后的意义，以及如何想要表达自己内心的更深刻的想法。

在竞赛辅导中，我们有专门的时间讨论画面的意义、要表达的情感、形式和方式，就会有综合的思考，再尝试把自己的想法表达出来。这样，我对自己的画理解得更透彻，对它感情更深刻，画好后也更有成就感。就是不仅把好看的东西画下来了，还表达了我想表达的事情。

【章老师】在辅导过程中，是否还有一些，令你感觉很有收获的技能？

【袁同学】在谷歌艺术通过自己想表达的色调，来搜索相应的作品，能见识并对比同一个色调的不同画风、画法、表达方式，这对我帮助很大。

【章老师】我记得你说这是当时你觉得自己最好的作品，为什么这么说？

【袁同学】当时我刚开始接触速写，还没有画过这么完整的作品，一直也想有一幅完整的创作。而且平时，我不会画这么细致，这幅画给我的体验是，它让我体验了非常丰富的画面、细致的笔触，而且找到了各种各样的素材，用自己的想法来诞生出一幅完整的画。

【章老师】创作过程中，会有怎样的心情？

【袁同学】这段时间因为本身要参加绘画比赛，所以我光明正大地花好长时间来画画。不然平常我爸妈问起来我在干嘛的时候，我总不能说我课外花了2个多小时在自己画画，就非常开心。这幅画用了2个多小时完成。

【章老师】最后，有推荐给其他同学的漫画吗？

【袁同学】一本是生活蒙太奇，作者记录了自己的日常生活，一些平常又温暖的小事情，还加入了一些奇思妙想，画风很温馨。它的色彩也很明亮，让我整个人的心情变好。

另一个漫画是非人哉，非常可爱的小漫画，里面的角色都不是人，是很短的一个个独立故事，很有意思也很治愈，画风可爱，有一段时间我特别喜欢他的画风。
